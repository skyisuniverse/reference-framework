# Reference

[Programming language reference (Wikipedia)](https://en.wikipedia.org/wiki/Programming_language_reference)

In computing, a programming language reference or language reference manual is part of the documentation associated with most mainstream programming languages. It is written for users and developers, and describes the basic elements of the language and how to use them in a program. For a command-based language, for example, this will include details of every available command and of the syntax for using it.

The reference manual is usually separate and distinct from a more detailed programming language specification meant for implementors of the language rather than those who simply use it to accomplish some processing task.

There may also be a separate introductory guide aimed at giving newcomers enough information to start writing programs, after which they can consult the reference manual for full details. Frequently, however, a single publication contains both the introductory material and the language reference.

> What is a reference? (e.g. https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference )

In software development, a **reference manual is a repository of technical facts about a technology**.

Unlike tutorials or guides that teach you how to build something step-by-step, a reference is a structured, detailed dictionary of the language or tool's building blocks. Developers look at a reference to check the exact spelling, syntax, rules, and behavior of specific code elements.

## What You Find in a Technical Reference

Using the MDN JavaScript reference as an example, this type of documentation is broken down into precise categories:

- Built-in Objects: Definitions, properties, and methods for core elements (like Array, Math, or Date).
- Statements & Declarations: The syntax rules for code logic, control flow, and variables (like if...else, for loops, let, and const).
- Expressions & Operators: How math, comparison, and logic symbols work (like ===, +, &&, or ? :).
- Errors: Explanations of what went wrong when you see specific messages (like a SyntaxError or TypeError).

A **programming language reference** (or language reference manual) is a **formal documentation artifact designed for developers that explicitly defines a language's basic syntax, built-in components, and runtime semantics**.

Unlike introductory tutorials or deep-dive conceptual guides, a reference assumes prior programming knowledge. It serves as an authoritative, dictionary-like look-up to resolve ambiguity about how a specific element operates.
